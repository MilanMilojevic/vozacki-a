# Возачки А — локална вежбаоница

Вежбање теоријског испита за **А категорију** над званичном базом питања
(извор: јавни practice сервис на servisi.euprava.gov.rs, GUID за А категорију).

## Покретање

Најпростије: **дупли клик на `index.html`** (ради директно из фолдера).

Ако нешто заглави, отвори **`Pokreni.bat`** — диже мали сервер и сам отвара апликацију.

Ако браузер прави проблем са чувањем напретка преко `file://`, покрени мали сервер:

```
node serve.mjs
```

па отвори http://localhost:8137

## Шта ради

- **Учење редом** — сва 1327 питања, редом по областима; памти тачно где си стао;
  напред/назад, прескакање, скок на било који број („Иди").
- **Стране области/подобласти** — клик на област на почетној (или на мрвице изнад питања)
  отвара страну са статистиком, списком свих питања (✓/✗/·), филтерима „само погрешна" /
  „само неодговорена" и дугметом **Настави** — свака секција памти где си стао.
- **Пречице на тастатури** — ← → кретање · 1–9 избор одговора · Enter потврда/следеће.
- **Понови погрешна** — размакнуто понављање: погрешно → одмах у ред; погодак → враћа се
  **сутра**, па **за 3 дана**; излази после 3 поготка. „Вежбај и она која чекају" прескаче термине.
- **Мешано понављање** — сва питања, насумичан редослед (испитни осећај).
- **Обележена** — квачица „Обележи питање"; трајна листа.
- **Симулација испита** — **калибрисана на званични генератор** (измерено из 2 званичне
  еУправа симулације, 17.08.2026): иста матрица област × поени у сваком тесту — Правила 19/46п,
  Сигнализација 13/34п, Возило 2/4п, седам малих области по 1, Последице 0; укупно 41 питање,
  98 поена, 45 минута, праг 85%. Мрежа 1–41; погрешна иду у ред за понављање. Напуштање
  симулације тражи потврду и ништа не уписује.
- **Симулација је верна испиту и по интерфејсу**: нема сталне мреже питања — уместо ње дугме
  **„Извештај"** (табела Питање/Одговорено/Обележено, клик води на питање), „Обележи питање"
  постоји и током теста (после предаје обележена остају у твојој листи), навигација
  „Претходно/Следеће питање". Помоћи којих на испиту нема — нема ни овде.
- **Преглед покушаја** — клик на било који покушај у „Симулације до сада" отвара цео преглед:
  свако питање са ознакама „✓ тачан одговор" / „твој одговор" на самим опцијама, „Ниси
  одговорио" за прескочена, и напоменом „Тражи N одговора" код вишеструких (признаје се
  само ако су означена СВА тачна — као на испиту).
- **Одговор се увек потврђује** дугметом „Одговори" — и код једног одговора (клик само бира).
- **Статистика** — тачност по областима + најслабије подобласти.
- Ћирилица/латиница (остаје на истом екрану), извоз/увоз напретка.

Напредак се чува у браузеру (localStorage) — **преживљава рестарт браузера и рачунара**;
брише га само „брисање података прегледања". За сваки случај: на почетној
**„Повежи фајл за аутоматско чување"** — једном изабереш фајл и свака промена се уписује на диск.

Напомене о „чудним" стварима које су намерне (верност правом испиту):
- одговори почињу малим словом — они су наставак реченице питања, тако стоје и на испиту;
- „km/h" латиницом у ћириличном тексту — SI ознаке се по правопису увек пишу латиницом;
- **#7921** поред питања = званични МУП број питања (исти важи на еУправи).

## Објашњења

`explanations.js` садржи незванична објашњења (основ: ЗОБС, са бројем члана) и појмовник-картице.
Приказују се после одговора у учењу/понављању и у прегледу симулације — **не** током симулације.
Извор и генератор: `tools/build-explanations.mjs` (латинични извор, аутоматска ћирилица).
Покривено: Возач (8), Превоз терета и лица (6) + картица „Категорије возила" (чл. 7).

## Ажурирање базе (ако МУП измени питања)

```
cd tools
node harvest.mjs <GUID-за-вежбање> 15 base-A.json
node harvest.mjs <GUID-за-вежбање> 9 base-A-cyr.json
node build-data.mjs
node download-images.mjs base-A.json ../img
```

База преузета: 2026-08-17. Питања су јавна; дозвољена је репродукција у некомерцијалне сврхе.
