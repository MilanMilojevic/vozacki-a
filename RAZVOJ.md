# Развој и одржавање

Кратак водич за свакога ко буде мењао ову апликацију — укључујући будућег себе.

## Шта је ово

Вежбаоница за теоријски испит **А категорије** над званичном базом питања (еУправа).
Нема сервера, нема базе података, нема билд корака за саму апликацију: то је обичан
HTML + CSS + један JS фајл. Напредак се чува у `localStorage` прегледача.

## Покретање

| Начин | Како | Напомена |
|---|---|---|
| Најпростије | двоклик на `index.html` | ради директно из фолдера (`file://` режим) |
| Ако нешто заглави | двоклик на `Pokreni.bat` | диже локални сервер на порту 8137 и отвара прегледач |
| Ручно | `node serve.mjs` па `http://localhost:8137` | исто као горе |

**`file://` режим:** прегледач таквој страници не дозвољава мењање адресе
(origin је „null"), па апликација то препознаје (`FILE_MODE`) и уопште не дира
адресу — све навигације су у самој страници. Преко сервера ради пуно рутирање
преко hash-а (`#/sek/c30`), што омогућава дубоке линкове и дугме „назад".

## Структура

```
index.html          костур странице (све „екране" држи као <section class="view">)
app.js              цела апликација (један IIFE, без зависности)
style.css           стилови, укључујући тамну тему (body.dark) и широке екране (≥1200px)
data.js             ГЕНЕРИСАНО — питања, области, подобласти
explanations.js     ГЕНЕРИСАНО — објашњења по питању + картице појмовника
version.js          број верзије (за обавештење „стигла нова верзија")
img/                слике питања (704 комада)
serve.mjs           мали статички сервер за локални развој
tools/              алати за освежавање података (види доле)
tools/arhiva/       примењене једнократне закрпе — историја, не покретати поново
```

### Екрани

Сваки екран је `<section id="view-XXX" class="view">`. Приказује се додавањем
класе `active` (`show('browse')` у `app.js`).

> **Замка:** ако у CSS-у пишеш `#view-home { display: … }`, то ће надјачати
> `.view { display: none }` и екран ће остати видљив преко свега. Увек пиши
> `#view-home.active { display: … }`. Провера:
> ```bash
> grep -oE '#view-[a-z]+\s*\{[^}]*display:' style.css | grep -v '\.active'
> ```
> (излаз мора бити празан)

### Алати (`tools/`)

| Алат | Чему служи |
|---|---|
| `harvest.mjs <guid> <lang> <out>` | преузима базу питања са еУправе (треба важећи GUID за вежбање) |
| `build-data.mjs` | од `base-A.json` прави `data.js` |
| `download-images.mjs` | преузима слике питања у `img/` |
| `build-explanations.mjs` | од извора у самом фајлу прави `explanations.js` |
| `bump-version.mjs` | подиже број верзије и ознаке у `index.html` |
| `patch-srpski.mjs` | једнократна језичка исправка (задржано ради историје) |

**После сваке измене** било ког фајла који `index.html` учитава са `?v=` — то су `app.js`, `style.css`, `data.js`, `explanations.js` и сам `index.html` — покрени:

```bash
cd tools && node bump-version.mjs
```

Тиме се мења `version.js` и `?v=` ознаке у `index.html`, па прегледач узима нове
фајлове, а отворени табови добијају траку „Стигла је нова верзија".

## Конвенције

### Двојно писмо (латиница + ћирилица)

Сваки текст видљив кориснику постоји као пар `{ l: 'latinica', c: 'ћирилица' }`.
У `app.js` то су уноси у објекту `STR`, а испис иде кроз `L('kljuc')`.

Објашњења се **не пишу двапут**: у `build-explanations.mjs` пише се само латиница,
а ћирилица се добија аутоматским пресловљавањем при билду. Пресловљавач чува
ознаке које морају остати латиничне (`km/h`, `kW`, `cm³`, `mg/ml`, `kg`, категорије
`AM`/`A1`/`A2`/`A`/`B`, натписи на знаковима `STOP`, `BUS`).

> **Провера после билда:** излаз мора бити празан.
> ```bash
> node -e "const s=require('fs').readFileSync('explanations.js','utf8');console.log((s.match(/[A-Za-zčćžšđ][Ѐ-ӿ]|[Ѐ-ӿ][a-zčćžšđ]/g)||[]).filter(t=>!/^n/.test(t)))"
> ```

### Уређивање `tools/build-explanations.mjs`

Фајл садржи **NUL бајтове** (користе се као граничници при пресловљавању), па
уобичајени алати за уређивање знају да га оштете. Мењај га **скриптом** која ради
`split`/`join` над тачним низом и гласно пада ако низ није нађен тачно једном —
образац видљив у `tools/arhiva/`.

### Провера садржаја (научено на грешкама)

Сваку **визуелну** тврдњу (боја, облик, положај руке на знаку) провери **отварањем саме слике**
`img/<qId>.jpg` — текстуална провера не хвата грешке у бојама. Тако је нађено да је картица
tврдила да је почетак аутопута плава табла, а он је **зелен** (слике 9155/9083).

### Објашњења

- Свако објашњење креће од **тачног одговора баш тог питања**, па објашњава зашто.
- Замке (примамљиви нетачни одговори) се именују и разрешавају.
- Чланови закона се наводе **само после дословне провере** у тексту закона.
- Казнене мере: **без динарских износа** (мењају се изменама закона) — уче се класе.
- Где се званични одговор разилази са важећим законом, текст то каже поштено
   („у испитној бази…"), без измишљања.

## Симулација испита

`SIM_SLOTS` у `app.js` описује шаблон правог испита изведен из **пет званичних
извлачења** (данас их је шест): 41 питање, 98 поена, 45 минута, праг 84 поена (85%).
Распоред по областима је фиксан (нпр. Правила 19 питања/46 поена, Сигнализација
13/34, Последице 0), а питања се бирају насумично унутар сваке ћелије.

Симулација је намерно **верна испиту** — без помоћи којих на испиту нема
(нема објашњења док траје, нема мреже питања, увек светла тема).

## Провера пре објављивања измене

За сваку измену која дира УЧЕЊЕ, РЕД ПОНАВЉАЊА или СИМУЛАЦИЈУ обавезно и
аутоматска провера бодовања: отвори http://localhost:8137, у конзоли налепи садржај
`tools/provera-bodovanja.js` па позови `proveraBodovanja2()` — све ставке морају PASS (број пише на крају излаза: „✓ SVE PROŠLO (N)")
(укључујући целу симулацију 41/41 → 98/98). Ради на привременом стању и врати твој напредак.

```bash
node -e "new Function(require('fs').readFileSync('app.js','utf8'))"   # синтакса
cd tools && node build-explanations.mjs                               # билд + скенер писма
cd tools && node bump-version.mjs                                     # нова верзија
```

**Провера цртежа мери се на 375×812** (у уграђеном прегледачу: viewport = mobile). У
сакривеном окну `innerWidth` је 0 и све мере исцртаног су нуле — провера то сама одбија.

**Ако измена дира `sw.js`, `version.js` или `index.html`:** продукцијска кеш-грана (`?v=`
cache-first) се на localhost-у НИКАД не извршава, па се офлајн понашање тамо не може
проверити. После објаве отвори живу адресу, сачекај да service worker пређе на нову
верзију, па у конзоли: `(await caches.open('va-core-v' + APP_V)).keys()` — мора да врати
`index.html`, корен и свих пет фајлова са `?v=`. Тек тада једно онлајн учитавање заиста
оставља апликацију спремном за рад без интернета.

Затим у прегледачу: отвори почетну, уђи у једну област, одговори на питање,
отвори статистику и појмовник. Ако нешто пукне, апликација исписује **црвену
траку са поруком** на врху странице.

## Умеци и плакат

`embed.html` — самостална страница са једним насумичним питањем, за уградњу на сајтове
ауто-школа (учитава `data.js` са јавне адресе). `plakat.html` — А4 плакат са QR кодом.
QR се прави са `tools/napravi-qr.mjs` (без спољних библиотека), а **обавезно се проверава**
са `tools/proveri-qr.mjs` — тај скрипт чита код назад из слике и мора да испише тачну адресу.

## Права

Питања, одговори и слике су из јавног сервиса еУправе (МУП Србије) и користе се
некомерцијално, за лично учење. Код апликације је ауторски рад власника
репозиторијума.

## Правила која су ушла у код 02.09.2026 (да не би била поново измишљана)

- **Типографска скала** — `--fs-xs/sm/md/lg` у `:root` су једине дозвољене величине текста
  (осим наслова и „украсних" бројева). Нова величина се НЕ уводи; бира се најближи токен.
  Уграђени (inline) `style="font-size…"` у `app.js` не сме да постоји — разреди су `.napomena`, `.tekstSm`,
  `.istaknuto`.
- **Боје** — свака боја која се користи по правилима је токен у `:root` (са тамним парњаком у
  `body.dark`). Голе хекс вредности смеју само: `#fff` на обојеној подлози и вредности које су
  саме „тамна варијанта" нечега.
- **Облик контроле прати последицу** — `.primary` једна главна радња по екрану, `.secondary`
  мења стање/покреће посао, `.danger` неповратно брише, веза (`.bcLink`, `<a>`) САМО за
  кретање или спољну адресу. Ниједна акција није нацртана као линк.
- **Заједнички цртач области** — `nacrtajOblasti(kontejner, {tacnost})` црта редове области
  и на почетној и у статистици (траке, бројачи, клик → списак, стрелица → акордеон подобласти).
  Ако се мења изглед реда, мења се на једном месту.
- **Одељци збирних картица** — у `tools/build-explanations.mjs` одељак се обележава
  `<div class="kSek" data-sub="138">…</div>`. Уз питање се приказују само одељци те
  подобласти (`suziKarticu`), уз дугме „Прикажи целу картицу"; у појмовнику се види цела.
  Више подобласти: `data-sub="138,141"`.
- **Распоред понављања** — тачан одговор помера распоред САМО кад је питање на реду
  (`dueOf(id) <= now`); тачан одговор пре рока је вежбање (`r.a++`, без `streak`/`due`);
  погрешан важи увек. Исто питање улази у дневне бројаче највише једном дневно.
  Тестови у `tools/provera-bodovanja.js` кодирају ова правила — кад се правило
  мења, мења се и тест, свесно.
- **Освежавање** — утврђено питање невидјено дуже од 21 дан (`OSVEZI_POSLE`) улази у
  `zaOsvezavanje()`; не дира `inQueue/dueOf`. Тачан одговор обнови датум, погрешан враћа у ред.
- **Текстови** — сваки `{ l, c }` пар се пише ручно; ћирилица не сме да садржи латинична
  слова осим: km/h, ЛАТ, GitHub, Enter, назива прегледача и чувара `#A/#B/@1/@2`.
  Чувари у тексту су `@1`, `@2` (никад `#` — оно се појављује дословно у „#број").

## Правила из пролаза испочетка (v97, 02.09.2026)

- **Један речник понављања** — „за понављање" је кровни појам (све у реду), „данас" и
  „касније" су његови делови (`ponDanas`/`ponKasnije`). Речи „спремно"/„чека" се више не
  користе. Објашњење правила (`queueTip`) стоји иза дугмета „?" (`pomocHtml` +
  `pomocTekstHtml` + `veziPomoc`) и отвара се на месту — никад само у облачићу.
- **Три стања у списку** — `✓` утврђено, `✗` погрешено (у реду), `◐` тачно из прве које чека
  једну потврду (`.qWait`). Тачан погодак никад не носи црвени знак.
- **Једна формула темпа** — `predlogTempa(dana, neodg)` (са резервом) храни и сажетак на
  почетној и „Предложи ми". Кад циљ постоји, сажетак не нуди други број; ако циљ не стиже до
  краја градива, каже то (`planPremalo`). Квота без градива је испуњена (`nemaNovih`/`nemaPon`).
  Одговор пре рока не пуни квоту понављања (`S.day.pon` само кад `!preRoka`).
- **Праг испита** — `PRAG_UDEO = 0.85`, `prag(total)`, `pragTekst(total)`; нигде више „84"
  уписано руком. Боја тачности: `accClass(acc)` (≥85 зелено, 70–84 жуто, <70 црвено) на
  свим местима. Предлог симулације: `SIM_PREDLOG_OD = 80` преко `readiness()` — исто
  правило цитирају водич и тура.
- **Датуми** — `fmtDatum(x, vreme)` → `dd.mm.gggg.`; датум последње провере базе је
  константа `BAZA_PROVERENA` (подножје + картица поверења).
- **Дугме не наслеђује величину картице** — `button { font-size: 1rem }`; `.primary`
  користи `--primaryBg/--primaryBgH` (не `--blue`, који у тамној теми посветли), трака на
  врху `--topbar`. Правило за `body.dark .primary` НЕ сме да се врати — оно је прегазило
  `--btnOff` и угашено дугме је изгледало упаљено.
- **Наслови група** — један разред `.grupaNaslov` (подешавања, појмовник, области у „Сва
  питања", подобласти у области). Размаци: `.opisRed`, `.razmakG`, `.card h3 ~ h3`; уграђени
  `style="margin…"` постоји још само у извештају симулације (намерно нетакнут).
- **Склопиве картице** — ЈЕДАН образац: `.pojBtn` + `sklopivo(btn, grupa, cilj)`; стрелица
  `▸/▾` долази из `aria-expanded`. Водич памти стање у `S.guide` слушачем ПОСЛЕ `sklopivo`.
- **Једно питање преко адресе** (`#/p/ID`) — `startList(..., { jedno: true, nazadLbl, hash })`:
  без бројача „1 од 1" и поља „Иди", назад води на почетну, „даље" покреће подобласт.
- **„Настави" на Сва питања** — `prviNeodgOd(S.seqPos)`: прво неодговорено од места где је
  стао, да план дана и области не би враћали на питање 1. На страни области „Настави" иде
  тачно од места (`contTipSec`) — два понашања, два текста.
- **Промена писма усред питања** — `prikazPitanja` (по `recordKey`) памти редослед понуда,
  избор и дат одговор; важи САМО док траје `current.redraw()` из промене писма
  (`ponovniPrikaz`). Стрелице назад-напред и даље нуде питање изнова — тако раде исправке
  одговора и тако су писани тестови.
- **Дани до испита** — `danaDoIspita()` (round над две локалне поноћи); ниједан `ceil`.
- **Паукал** — `few(n)` + `novihPitanja(n)`: „1 ново питање / 3 нова питања / 5 нових питања";
  бројеви питања иду кроз `nQ(n)`. Реченицу која има број НЕ писати са придевом „ручно".

## Навигација и повратна информација (v99, 03.09.2026)

- **Једна контрола за почетну** — бренд, ЦЕНТРИРАН у траци (`#topbar` је мрежа `1fr auto 1fr`).
  Дугме „Почетна" десно је укинуто, као и „На почетну" из заглавља спискова (остаје на крају
  списка и у резултату, где је избор одредишта). Не додавати нове улазе на почетну.
- **„Назад" је увек на истом месту** — лево у траци, преко `postaviNazad(tekst, fn)`;
  `show()` га брише при сваком преласку, па га екран поставља ПОСЛЕ `show()`. Појављује се само
  кад родитељ НИЈЕ почетна (подобласт → област, питање → његов списак).
- **Доња навигација (`#donjaNav`)** — само на ≤700px, пет одредишта, стање преко
  `aria-current="page"` (`oznaciNav`). У симулацији се склања (`body.uSimulaciji`), као и подножје.
  Плутајуће траке (`#trakeDrzac`, `#iosHint`, `#updBar`, `#repoUpd`) се померају изнад ње —
  то правило МОРА да стоји на КРАЈУ `style.css` (њихове основне дефиниције долазе касније у фајлу).
- **Величина слова** је у подешавањима (група АПЛИКАЦИЈА), не у траци: подеси се једном.
  Дугмад се цртају са картицом, па `applyFont()` мора да се зове после цртања и да трпи њихово
  одсуство; клик иде делегирано са `document`.
- **Једна повратна информација** — `poruci(tekst)`: кратка трака при дну, `role="status"`, сама

## Темпо који рачуна стварност (v112, 04.09.2026 — тура 1)

Милан: „можда и јесте препрека за испит, треба да се напомене, да се темпо мења… и ако одрадимо
више од дневног циља да и то уђе у рачуницу".

- **Ауто режим (`S.plan.auto`)** — дневна квота се изводи из онога што је ОСТАЛО и броја дана до
  испита, сваког дана изнова: `cNovih = ceil(neodgovorenih / danaZaNovo)`,
  `cPon = min(120, max(20, cNovih + ceil(наРеду / dana)))`. Зато вишак урађен данас САМ снижава
  сутрашњу квоту — не памти се никакав дуг. Без датума испита ауто нема од чега да рачуна и то каже.
- **Пресуда уместо утехе.** Три гране, свака са бројевима, све три доња граница (не прогноза):
  · **стижеш** — градиво и понављања стају у преостале дане;
  · **градиво да, понављања не** — колико питања ће се видети само једном;
  · **не стижеш градиво** — „то ЈЕСТЕ препрека", са бројем питања која остају невиђена.
  Рачун: `otvoriS = min(neodg, cNovih × dana)`, `potrebnoPon = наРеду + otvoriS`,
  `kapacitetPon = cPon × dana`. Свако ново питање улази у ред (`inQueue`) и тражи бар једну потврду —
  отуда сабирак.
- **Лостови су дугмад са бројем**, не савети: „Подигни на N нових и M понављања" и
  „Учи прво оно што се на испиту и појављује".
- **Приоритет по тежини на испиту (`S.plan.prio`)** — нова питања иду редом по `tezinaPodoblasti()`,
  изведеној из званичног шаблона `SIM_SLOTS` (слот са више подобласти дели јединицу на њих:
  претицање 134 носи 5, брзине 135 три, подобласт 91 нула). Ко нема времена за све, изостави
  оно што се ретко и појави, а не оно докле се стигло по редоследу базе.
- **Вишак се види:** „данас си урадио 90 нових, а циљ је 65 — 25 преко циља" (+ у ауто режиму
  „сутрашња квота ће зато бити мања").
- Провере: 45 ставки (девет нових за темпо и приоритет). Датум у тестовима мора да буде ЛОКАЛНИ
  (као `localDay()`), не `toISOString()` — иначе `S.day` не важи за данас и квоте испадну нула.

## Шанса да положиш и правило о симулацијама (v113, 04.09.2026 — тура 2)

Милан: „колико симулација би требало да прођемо, и колико да положимо да бисмо имали

  а претпоставка је независност слотова, што стоји у самом објашњењу на екрану.

  дакле ни близу онога што „80 поена" сугерише.
- **Правило од четири ставке (`spremnost()`)**, свака са бројем и ✓/✗:
  бар 5 симулација · рађене бар 3 различита дана · последње 3 положене са бар 5 поена преко
  прага · процена бар 85%. Разлог зашто ниједна сама није довољна стоји у тексту: при стварној
  шанси од 70% три положене заредом дешавају се у трећини случајева.
- Приказ: Статистика носи и очекиван резултат и шансу и списак од четири ставке; дугме „Испит"

## Трећа тура: рад без интернета, описи цртежа и остатак ситница (v131, 17.09.2026)

**Једно учитавање на мрежи сада ЗАИСТА оставља апликацију спремном за рад без интернета.**
До сада је `install` био гола `skipWaiting()`, а `activate` одмах брише сваки кеш који није
текући — нови кеш је зато био ПРАЗАН, а стари обрисан. После сваког издања (и после прве
посете уопште) офлајн је радио тек ако си случајно отворио баш оне стране које си већ
посетио. Сад `install` пуни кеш пре него што активација обрише стари, а **списак фајлова се
ЧИТА из `index.html`** уместо да се преписује у `sw.js` — преписан списак би пре или касније
отишао у страну, `addAll` би падао на 404 и издање никад не би прошло, и то нечујно.
Уз то је ажурирање постало **све-или-ништа**: ако веза пукне усред инсталације, ново издање
не активира, а старо (потпуно кеширано) остаје нетакнуто.

**Провера издања више не гомила кеш.** `version.js?ts=<време>` је сваки пут ДРУГА адреса, а
општа грана је кеширала сваки успешан одговор — у дуго отвореном табу број уноса је растао
на сваких пет минута, до следећег издања.

**Порука кад нема ни интернета ни кеша** била је гола ћирилична реченица у `text/plain`.
Сад је страна у оба писма, са дугметом „покушај поново" и у духу апликације.

**Упутство „преузми ZIP и препиши преко фасцикле" више не искаче онима који апликацију
отварају са адресе** — они је ажурирају освежавањем. Трака „Стигла је нова верзија · Освежи"
сада постоји на ЈЕДНОМ месту и служи и аутоматску проверу и ручно дугме у подешавањима, а
мења писмо кад га промениш. „Не проверавај аутоматски" више не баца на почетну.

**Сваки цртеж је сада или ОПИСАН или УКРАС.** Од 199 цртежа њих 78 су сличице знака поред
којих одмах стоји и име и опис речима — читач екрана их је читао као засебно „Увећај цртеж",
па је иста ствар ишла двапут, а свака је била и станица за тастатуру. Правило је уведено у
БИЛД (цртеж без `aria-label` и без `role="img"` је украс), па важи и за све будуће цртеже.

**`aria-label`, `alt` и `title` се сада преводе на ћирилицу.** `toCyr` чува све унутар `<…>`
да не поквари атрибуте — али та три атрибута нису код него текст који човек ЧУЈЕ или види у
облачићу, па су у ћириличном режиму остајали латинични. (Ово није било у списку налаза —
нађено је при провери налаза о описима цртежа.)

**Остале потврђене ситнице:** застарела адреса области падала је кроз `TypeError` уместо кроз
предвиђени повратак на почетну · тема „прати систем" није слушала промену система уживо ·
стрелица области имала је исти назив за свих десет области · дугмад теме и писма нису

## Рад без интернета: три рупе у кешу (v141, 17.09.2026)

**Обећање из в131 — „ако веза пукне усред инсталације, старо остаје нетакнуто" — није важило.**
Општа грана сервисног радника уписивала је СВАКИ успешан одговор у кеш, укључујући и саму
навигацију, и то под кључ `./` — исти онај који пише инсталација, заједно са свих пет `?v=`
фајлова на које тај HTML показује. Стари радник и даље отвара свој `va-core-vNNN` (копију
`version.js` држи `importScripts`), па је нов `index.html` слетао у СТАР кеш и заклањао сагласну
копију. Исход: офлајн добијеш неоформљену љуску која тражи пет фајлова којих тамо нема.

Нов HTML сад иде под свој кључ (`./?mreza`) и служи само као ПОСЛЕДЊА резерва — за случај да
инсталација никад није прошла, а страна је бар једном потпуно учитана.

**Мерено на самом `sw.js`** (покренут у `vm`-у са лажним `caches`/`fetch`, шест сценарија):

| сценарио | пре | после |
|---|---|---|
| веза пукла усред издања, па офлајн | љуска в136 без иједног свог фајла | **сагласна в135** |
| инсталација никад + офлајн | ради | ради (без промене) |
| `version.js?ts=` без мреже | 503 + `text/html` | **празан 504** |
| навигација без ичега у кешу | офлајн страна | офлајн страна (без промене) |
| слика на `localhost` | кеширана заувек | **радник се склања** |
| слика на Pages-у | кеш-први | кеш-први (без промене) |

**Офлајн страна враћала се и ономе ко није страна.** `version.js?ts=…` се повлачи на сваких пет
минута и при сваком повратку у таб; без мреже је уместо скрипте стизао HTML, који прегледач
ИЗВРШИ и баци `SyntaxError`. Функција није пуцала (провера издања тихо одустане), али је конзола
на сваких пет минута изгледала као да апликација пуца. Сад све што није навигација добија исти
празан 504 као и остале две гране.

**На `localhost`-у слике су се кеширале заувек** — иако на два места пише да се на локалу кеш не
користи, а `serve.mjs` шаље `no-cache` за сваки фајл. Ко замени слику, до сад ју је гледао стару
док не обрише кеш руком.

**Уз то, ситна хигијена коју је ревизија нашла:** `finishSim` је рачунао збир по областима који
нико не чита (преглед га гради изнова из записа, зато и ради за старе испите); изнад `naIspitu`
стајала су ДВА комментара са различитим пореклом истог броја (стари је описивао ручну табелу
обрисану у в118); комментар о сликама тврдио је 334, а мерено је 344 — број је сад скинут из
комментара и остављен билду, који га ионако испише; и `tools/atlas.mjs` је био једини фајл у
репоу са CRLF крајевима редова, што је већ једном покварило сидро при закрпи.
