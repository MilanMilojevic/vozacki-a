# Архива једнократних закрпа

Овде стоје скрипте које су **већ примењене** и не покрећу се поново.

Свака је једном изменила `tools/build-explanations.mjs`, `app.js`, `style.css` или
`index.html` и тиме постала део тренутног стања. Чувају се из два разлога:

1. **Историја** — види се тачно шта је и када мењано (уз `git log`).
2. **Образац** — показују како се безбедно мења `tools/build-explanations.mjs`,
   који садржи NUL бајтове па га обични алати за уређивање знају оштетити:

```js
const cnt = s.split(stariNiz).length - 1;
if (cnt !== 1) { console.log('FAIL count=' + cnt); process.exit(1); }  // гласан пад
s = s.split(stariNiz).join(noviNiz);
```

> **Не покретати ове скрипте.** Друго покретање или неће наћи свој низ (па ће
> пасти, што је безазлено), или ће дуплирати измену.

Групе по називу:

| Префикс | Шта је радила |
|---|---|
| `add-batch*` | додавање тура објашњења (по подобластима) |
| `fix-batch*` | исправке после независних ревизија тих тура |
| `add-card-*`, `add-*-svg` | нове картице појмовника и њихови цртежи |
| `polish-*`, `fix-*align*` | поравнања и дотеривање приказа |
| `fix-filemode`, `fix-robustnost` | понашање при отварању фајла директно (`file://`) |
| `apply-topups` | примена допуна о нетачним одговорима (замкама) |
